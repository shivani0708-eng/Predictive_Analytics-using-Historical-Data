# Predictive Analytics Using Historical Data

## Overview
This project predicts future sales using historical data with Linear Regression.

## Features
- Load historical data
- Train Linear Regression model
- Predict future sales
- Visualize historical and predicted data
- Save predictions to CSV

## Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Files
- historical_data.csv
- predictive_analytics.py
- predicted_data.csv
- prediction_graph.png

## Run

```bash
python predictive_analytics.py
```
